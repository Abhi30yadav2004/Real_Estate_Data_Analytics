# 🏠 Real Estate Data Analytics Project

## 📌 Project Overview
This project analyzes real estate housing data to understand the factors affecting house prices and property trends.  
The analysis is performed using **Python**, **Excel concepts**, **SQL thinking**, and visualized using **Power BI**.

---

## 🎯 Problem Statement
- What factors influence house prices?
- How does area, bedrooms, parking, and furnishing affect pricing?
- What is the average price of premium houses (area > 2000 sqft)?

---

## 🛠 Tools & Technologies Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- Power BI
- CSV Dataset (Kaggle)

---

## 📂 Dataset
- Source: Kaggle (Housing / Real Estate Dataset)
- Format: CSV
- Key Columns:
  - Price
  - Area
  - Bedrooms
  - Bathrooms
  - Parking
  - Furnishing Status

---

## 📊 Analysis Performed
- Data Cleaning & Preprocessing
- Conditional Filtering (Area > 2000 sqft)
- KPI Calculations:
  - Average Price
  - Maximum Price
  - Total Properties
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Interactive Dashboard using Power BI

---

**Key Insights:**
- Larger area houses (>2000 sqft) have significantly higher average prices
- Price increases with number of bedrooms and parking
- Furnished houses tend to cost more
